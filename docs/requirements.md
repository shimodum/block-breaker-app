# ブロック崩しゲーム 要件定義書

**バージョン：** 1.0（初版）  
**開発状況：** 開発中

※ 本書は現時点での要件をまとめたものであり、開発の進行に応じて変更する可能性があります。

## 1. アプリ概要

ブラウザ上で遊べるシンプルなブロック崩しゲームを開発する。

プレイヤーはパドルを操作してボールを跳ね返し、画面上のブロックをすべて破壊することを目指す。

また、ユーザー登録・ログイン機能やスコアランキング機能を実装する。

## 2. 開発目的

- Laravel、JavaScript、Python（FastAPI）を使用したWebアプリケーション開発の学習
- フロントエンドとバックエンドの連携について理解する
- ユーザー認証、データベース操作、API通信の基礎を学ぶ

## 4. 画面一覧

| 画面 | 内容 |
|---|---|

## 5. 主な機能

| 機能 | 内容 |
|---|---|
| ゲーム開始 | STARTボタンでゲームを開始する |
| パドル操作 | キーボードまたはマウスで操作する |
| ブロック破壊 | ボールが当たるとブロックが消える |
| スコア表示 | ブロック破壊時に得点を加算する |
| ライフ管理 | ボールを落とすとライフが減少する |
| ゲームオーバー | ライフが0になるとゲーム終了 |
| ゲームクリア | すべてのブロックを破壊するとクリア |
| 一時停止・再開 | Spaceキーでゲームを停止・再開する |
| リスタート | ゲーム終了後にRキーで再スタートする |
| 効果音・BGM | ゲーム中の効果音や8bit風BGMを再生する |
| ユーザー認証 | ユーザー登録・ログイン・ログアウト |
| スコア保存 | プレイ結果をデータベースに保存する |
| ランキング | 保存されたスコアを順位順に表示する |

## 6. ゲームの基本ルール

- ブロックは4行×7列の合計28個とする。
- ブロック1個につき10点を加算する。
- ライフは3つから開始する。
- ボールを落とすたびにライフが1つ減る。
- ライフが0になるとゲームオーバーとなる。
- すべてのブロックを破壊するとゲームクリアとなる。
